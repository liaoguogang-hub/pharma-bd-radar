# 事故复盘：b4985179「礼来×诺诚健华」稿件内容失实（2026-10-11 成稿 / 2026-10-16 复盘）

## 一句话

源头是一篇**短新闻**（一条公告转述），成稿阶段把公告里的一个**实体标签 "TYK2"**误当成
交易标的，又从模型世界知识里补出**源数据里根本不存在的分子名、临床阶段、历史收购年份和金额**，
最终把"一个泛化的多靶点发现平台合作"写成了"诺诚健华 TYK2 平台授权"，与公告有明显出入。

## 数据流与出错点

```

        │  素材里 TYK2 只作为摩熵的【实体标签】出现在正文前的一行元数据里，
        │  交易本身从未说是 TYK2 —— 原文是"专有药物发现平台…至多5项创新性靶点"。

        │  这段 reasoning 之后被当作"选题理由"喂给成稿阶段。

        ▼

```

**正确的核心事实**（应当如此表述）：2026年9月24日生效，礼来与诺诚健华全资子公司北京诺诚健华
签**研发合作及授权许可协议**，诺诚健华依托**专有药物发现平台**发现并开发**至多5项创新靶点**；
礼来付最高1亿美元首付款+近期里程碑，潜在研发及商业化里程碑约32.5亿美元，潜在总额约33.5亿美元；
个位数百分比分级特许权使用费；设联合指导委员会。**标的靶点未披露**——"TYK2"不是已披露的交易内容。

## 三个根因

1. **短素材 + 强观点 = 脑补**。素材只有一段公告转述，但 prompt 要求 2800-3200 字。
   为了填字数，模型用世界知识（诺诚健华确有 TYK2 管线）补出 ICP-488、Dice 收购、
   竞对格局等，措辞还是"素材里没有的一律不得出现"的禁令也压不住。
2. **单一实体标签被误升格为交易核心**。新闻抓取在正文前保留了一行实体标签
   （`Eli Lilly & Co  TYK2  北京诺诚健华…  益方生物…`）。成稿模型把这行标签
   当成了交易信息。根子上是**标签与正文没有在数据结构上隔离**。
3. **评分阶段的 reasoning 会原样喂给成稿**，它一旦先下错判断（"TYK2平台"），
   后面所有环节都在错误前提上做加法，越写越实。评分本应"只选不判事实"。

## 为什么没被拦住

- compose 的 `validate_content()` 只做**结构校验**：字数、小节数、表格列数、
  标题与正文的金额口径自洽、空壳表、并购类要每股价/日期。**没有任何一条
  把成稿里的实体（公司名、分子名、靶点、数字）与素材做事实比对。**
- 金额口径（1亿/32.5亿/33.5亿、分层）恰好是对的，所以"金额自洽检查"也过了，
  反而给了错误的那些实体"可信"的掩护。

## 已落地的修复（2026-10-16）

### 修复 1：实体标签与正文隔离（数据层）

- `common.split_entity_tags()`：识别正文开头的 CMS 实体标签行，剥离成独立 `entity_tags` 列表。
  **三个信号必须同时成立才动手**（CMS byline+日期+阅读数 / byline 后≥2 个实体形态 token /
  标签后是足够长的新闻导语），任一不满足原样返回——刻意保守，误伤正文的代价更大。
- `RawItem.entity_tags` / `ScoredTopic.entity_tags` 贯穿管线；`fetch.fetch_article` 和
  `deepen` 一手抓取两条路径都调用。
- `compose.build_material` 把标签连同明确警告喂给成稿："新闻站自动标注的实体标签，
  不是公告披露的交易内容"。
- 实测：事故稿正确剥出 `['Eli Lilly & Co','TYK2','北京诺诚健华医药科技有限公司',
  '益方生物科技（上海）股份有限公司']`，正文从"近期，诺诚健华公告称…"干净开头；
  三个正常样本零误伤。

### 修复 2：事实闸门（成稿后校验）

- `compose.check_facts()`：抽取成稿里的药物代号（ICP-488/DC-806 形态）和靶点缩写，
  凡在素材里找不到的列为待核，并附加**可执行的**纠正指令（"删掉代号，改写公司背景"）。
- 已挂进 `validate_content()` 末尾，错误经 `feedback` 自动回灌重试循环。
- ⚠️ **踩过的坑（已修）**：最初用 `\b` 做词边界，结果**一个都抓不到**——Python 的 `\b`
  基于 `\w`，中文字符在 Unicode 里属于 `\w`，所以 `的ICP-488抑` 在 ICP 前没有边界。
  改用 `(?<![A-Za-z0-9])…(?![A-Za-z0-9])` 否定环视后才真正生效。
- ⚠️ **误伤修正**：`IL-17`/`IL-23` 等细胞因子族名被当成"捏造的分子代号"。
  已加 `_CYTOKINE` 白名单（生物学分类不是专利代号）。
- 实测：事故稿 3 个捏造代号全抓到；4 篇真实稿零误伤；合成边界用例 XYZ-999 正确报错。

### 修复 3：评分阶段只选不判事实

`score.py` 新增第 ⑩ 条：`reasoning` 会被原样喂给成稿当"选题理由"，禁止在里面下事实结论
（"自有 TYK2 平台授权"这类）；有疑问的细节放进 `verify_todo`。

### 用户新增规则：素材短就写公司背景

`compose` 提示词新增「素材很短怎么办」章节：篇幅不足时**介绍交易双方的公司背景**
（主营业务、产品线、研发方向）来补字数——这是公开常识，不产生事实风险；
但交易本身的靶点、分子代号、临床阶段、金额条款仍只能来自素材。
`LENGTH_HINT` 第 3 条同步改成优先扩写公司背景。
